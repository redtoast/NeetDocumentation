Meet NEET computers!

What is NEET?

NEET is a Minecraft mod for 1.21.1 (Fabric) that adds code executing computers to the world! These computers can actually run real code, inspired by ComputerCraft by Dan200 and its modern fork CC:Tweaked by SquidDev. NEET attempts to improve the base idea of previous computer mods, and creates a system with complex graphics, full user IO, Peripherals, and HTTP access!

But why a NEET computer?

NEET utilises full 800 x 600 graphics with 24 bit colors, support for alpha values, and a programmatic display that renders directly on the block model! It also has full filesystem support including binary files, partitions, and live rewritable OS folders.

But what about development?

For full disclosure, NEET is only being continuously developed by two people, with community help in places, I (redtoastneedsbutter) make the java side of the mod, and maintain this website, while SpSf(swoshswosh_01578) maintains the YSLua, NEETS lua interpreter.

If you have ideas for the mod or a desire to contribute, please join us on the discord server to submit suggestions, bug reports, or ask about contributing, we are always open to the community.
